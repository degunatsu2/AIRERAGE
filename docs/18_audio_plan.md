# 18. BGM と効果音の制作計画

ゲームの BGM と、一部の豪華な効果音を作る計画と進捗。道具の使い方は `tools/audio/README.md`。

## 1. 目的と方針（ユーザーの要望、2026-10-27）

- **曲の方向性**: 開放感があって透明感のある雰囲気（ジャンルはフュージョン）。**ステージに応じて曲のコンセプトを変える**。
- **参考曲**（特に参考にする 2 曲。ユーザー、2026-10-27）: 山本真央樹「GEOMETRIC DANCE」（音楽ゲームの曲。BPM 150、
  プログレッシブ・フュージョン。作曲者の説明は「爽やかで、目まぐるしく展開が変わる」）と、庭師「水晶しようぜ」（クラウドからは
  曲の情報を見つけられなかった。作曲者は音楽ゲームに曲を提供しているトラックメイカー）。
- **必要な曲**（後で増えるかもしれない）: タイトル、メニュー、キャラクター選択、ステージごとの曲（それぞれ残り 1 分の版も）、リザルト。
- **効果音**: 一部をもう少し豪華に（タイトルでの決定音、キャラクターの決定音など）。
- **作り方**: 曲を「コードで書いた楽譜」から書き出す（`tools/audio`）。旋律・和音・ドラムのパターン・ベースの型・音色・混ぜ方をすべて
  Python で書くので、同じコードから同じ音が出て、修正は差分で追える。耳で聞けないので、ラウドネス・真のピーク・帯域の釣り合い・
  ループのつなぎ目を数値で確かめ、聞こえ方はユーザーに確かめてもらう。
- **開発用の道具**: 好きなだけ追加してよい（ユーザー、2026-10-27）。追加できないときはその都度ドメインを許可してもらう。

- 導入は `bash tools/audio/install_audio_tools.sh`（Unity のエディタと同じく、使うときに入れる。約 5GB）。
- Surge XT の音色に入っている残響（Reverb 1・2 など）は、読み込むときに切る（残響は曲の側でまとめて掛ける。4.2）。
- 流れ: 楽譜 → 楽器ごとに鳴らす → 楽器ごとのエフェクト → 楽器ごとのラウドネスで釣り合いを取る → 残響と付点 8 分のディレイへ送る →
  仕上げ（中低域を少し減らし高域を足す、軽いコンプレッサー、リミッター、**-16 LUFS・真のピーク -1 dBTP 以下**）→ OGG（Vorbis、品質 6）。
- **ループ**: 前奏＋本体＋本体を続けて鳴らし、2 回目の本体を切り出す。1 回目の終わりの残響が頭に入るので、つなぎ目がない
  （つなぎ目の高域の強さが、続けて鳴らしたときと同じことを確かめた）。ゲームでは前奏を 1 回鳴らしてからループを鳴らす。

旋律の動機（モティーフ）の一部をそれぞれ共有して、対であることを強める**。

## 4. 作ったもの

### 4.1 制作の環境と最初のデモ（2026-10-27）

- **道具**: `tools/audio`（2 章）。楽譜の書き方（`notation.py`。小節線 `|` で各小節の長さを検査して書き間違いを見つける）、和音の
  記号と声部の配置、ドラムのパターン（16 分の文字列）、ベースの型（度数。根音は前の根音に近い高さを選ぶ）、伴奏のリズム（食いを含む）、
  ビブラート（長い音に少し遅れてかかる。ピッチベンド）、楽器ごとの書き出しの使い回し。
- **ATHLETIC のデモ**（`songs/athletic.py`）: E メジャー・150 BPM。前奏 4 小節（♭VI-♭VII の決め）→ A 8 → A' 8 → B 8（王道進行）→
  サビ 16（カノン進行）→ ソロ 16（♭VI-♭VII-I）→ A へ戻る。本体 89.6 秒。楽器: ドラム（Virtuosity）、指弾きのベース、ローズ、
  パッド、ストリングス、ベルのアルペジオ、金管、リード（2 つの音色を重ねる）、ソロ（シンセのギター）、DX のエレピ。
- **残り 1 分の版**: F メジャー・162 BPM。B → サビ → ソロの前半 → サビ（本体 71.1 秒）。ドラムを強く（4 つ打ち寄り、オープンハイハット）、
  16 分のアルペジオとベースのオクターブ。
- **効果音の案**（`sounds/menu_se.py`）: タイトルの決定 3 案、キャラクターの決定 3 案。
  - タイトル A: 金管と和音シンセの一撃、キラキラ、クラッシュとキック、低いドン。
  - タイトル B: エレピの分散和音、2 オクターブのベルのグリッサンド、パッド（透明感）。
  - タイトル C: 0.4 秒の上昇する風切りのあとにシンセの一撃（押してから山が来るまで少し遅れる）。
  - キャラクター A: キックとリムショット、低いドン、金管の短い一撃、金属のシャッ。
  - キャラクター B: シンセの金管とギターのパワーコード。
  - キャラクター C: 下がる風切りのあとに上がる 2 音のチャイム（0.3 秒遅れて山が来る）。

**確かめたこと**: 書き出したものを数値で確かめた（ラウドネス -16 LUFS、真のピーク -4.5 dBTP、オクターブごとの強さ、ループの
つなぎ目にクリックがない、楽器ごとの鳴っている区間が構成どおり）。⚠️ 曲と効果音の聞こえ方（旋律・音色・混ぜ方）は確かめられない。
ユーザーに聞いてもらう（5 章）。ゲームにはまだ入れていない（6 章）。

### 4.2 デモ 1 への回答と、デモ 2（2026-10-27）

**回答**（ユーザー）: テンポと雰囲気はとても良い。旋律はあまり好きではない（リズムが一定で、進行にメリハリがなく、のっぺりしている）。
残り 1 分の版への変え方は問題なし。残響が掛かりすぎ。シンバルの音がこもっている。効果音はタイトルが B、キャラクターが C の方向だが、
音が厚すぎて効果音に向かない（もっと音数を少なく、シンプルに）。

**ATHLETIC（デモ 2）**: 雰囲気・テンポ・調・楽器は残し、旋律と構成と和声を書き直した。
- 構成: 前奏 4（1 回だけ）→ **リフ** 4（曲の顔。リード・金管・ベースが 3+3+2 の区切りで同じ動き）→ A 8 → A' 8 → **B 8（ハーフタイム）**
  → **サビ 16（短 3 度上の G メジャー）** → **ユニゾン 8**（全員で 16 分の速い動き、4・8 小節目は決め）→ ソロ 8 →
  **ブレイク 8**（ドラムとローズだけに落とし、ベルがリフの頭をこだまのように鳴らし、後半でリフの形で上ってスネアの連打からリフへ）→ リフへ戻る。
  本体 108.8 秒。
- 旋律: 動機（速い上りから長い音へ）をくり返して変える。長い音・16 分の速い動き・休み・食いを混ぜ、4 小節ごとに息を入れて金管が答える。
  サビは素早く駆け上がって長い E6 へ、後半は A6 まで上がる。
- 和声: 副属七（G#7 → C#m、E7 → A）、B のベースは C# → B → A# → A → G# → G → F# と半音で下がる、サビは G メジャー
  （E の属七 B7 で E へ戻る）、ユニゾンは E の上に D・C の和音。
- 強弱: 場面ごとに全体の大きさを変える（A は -2.5 dB、B で -3 dB からサビへ盛り上げ、サビ +0.5 dB、ブレイク -2 dB から戻す）。
  測ると A が -18.2 LUFS、サビが -14.5 LUFS、ブレイクが -18.5 LUFS（デモ 1 はほぼ一定だった）。
- 残り 1 分の版: F メジャー・162 BPM で、リフ → B（ハーフタイムをやめて刻む）→ サビ → ユニゾン → サビ（本体 77.0 秒）。
- 残響: ホールを短く小さく（2.4 秒 → 1.6 秒）、各楽器から送る量を約半分に、Surge XT の音色に入っていた残響（パッド・ストリングス・
  金管）を切った。
- シンバル: ハイハット・ライド・クラッシュを Unruly Drums（CC0）に替えた（閉じたハイハットの重心が 4.4kHz → 10kHz、クラッシュの
  6kHz より上の割合が 5% → 25%）。部位ごとの音量はスネアに対して測ってそろえた（ハイハット -10 dB、クラッシュ -1 dB など）。

**決定音（案 2）**: 重ねる音を 1〜2 種類に減らし、余韻を 1.2〜1.6 秒に。押してすぐ鳴る（0.1 秒以内に一番大きくなる）。
- タイトル B1: エレピの和音を素早くかき鳴らし、上にベルを 1 音。B2: ベルの速い上りの 5 音。B3: エレピの 2 音とベルの 2 音を同時に（いちばん短い）。
- キャラクター C1: 上がる 2 音のチャイムだけ。C2: ごく短い風切りに重ねて 2 音のチャイム。C3: 2 音のチャイム（ベルとエレピ）と軽い低いドン。

**確かめたこと**: 数値で確かめた（ラウドネス -16 LUFS、真のピーク -3.3 dBTP、場面ごとのラウドネス、ループのつなぎ目にクリックがない、
旋律の長い音が和音とぶつからない（半音上の音を探して、意図した G#7 の上の E だけ））。⚠️ 聞こえ方はユーザーの確認待ち（5 章）。

## 5. 確認したいこと（ユーザー）

1. ATHLETIC のデモ 2（通常・残り 1 分）: 旋律・進行のメリハリ、残響の量、シンバルの抜け。
2. 決定音の案 2: タイトル（B1〜B3）・キャラクター（C1〜C3）のどれがよいか。

## 6. ゲームへの組み込み（次の段階。方向性が決まってから）

- 曲は `Assets/_Project/Audio/Music/` に OGG（Git LFS）で置き、前奏とループを分けて鳴らす（前奏を 1 回、続けてループ。2 つの
  AudioSource と `PlayScheduled` で隙間なく）。今のコードで合成している BGM（`ProceduralAudio`）は、曲のファイルがあればそちらを使う。
- 残り 1 分（COIN RUSH の予告）では、残り 1 分の版へ切り替える（小節の頭でクロスフェード【仮】）。
- 効果音は今の差し替えの仕組み（`UiSounds` の差し替えの音）を使い、タイトルの決定とキャラクターの決定は新しい種類の音として分ける。
- 音量はオプションの BGM・効果音の音量に従う。
