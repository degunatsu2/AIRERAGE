## 1. 目的と範囲

**目的**: 攻撃、キャンセル、ガード、ジャストガード、被弾、コンボ、吹き飛ばしによる撃破（ステージの外）を、データで調整できる形で作る。ロールバック（Phase 2）の上で、オンラインでも命中が全員の画面で一致することまで確かめる。**テーマは空中戦**（[01](01_game_design.md) 1.2）。

| 範囲に含める | 範囲に含めない |
|---|---|
| 攻撃の状態とフレームデータ。地上技1つと、空中の4種類（D-35） | 特殊アクション、必殺技、方向転換（Phase 5） |
| 命中の判定、ダメージ（HP はなく、記録だけ。コインへの変換は Phase 4）、ヒットストップ、のけぞり、吹き飛び | コイン、撃破報酬、試合の進行、復帰後の無敵（Phase 4） |
| ステージの外に出たときの撃破と、最後にダメージを与えた人の記録（D-23） | 本番用のアリーナ（Phase 6） |
| キャンセル規則（攻撃→攻撃はヒット時のみ、攻撃→ワイヤー、ワイヤー→攻撃）とワイヤーキャンセルのクールタイム（P-1） | キャラクターごとの差（Phase 5） |
| ガード、ジャストガード（D-21） | アニメーション（今は箱の色と線で示す） |
| ゲージの獲得 | |
| 検証用のダミーと、空中戦の検証用ステージ（足場が少なく、外に出ると撃破） | |

## 2. 構成の方針

- 戦闘のロジックは Core の `Degunatsu.Core.Combat`（純C#、決定的）。状態は `CharacterState.Action`（`ActionState`）などに値で持つので、巻き戻しと PC 間のチェックサムにそのまま乗る。
- 状態の遷移は `ActionController` の1か所で決める（[01](01_game_design.md) 6.3 の実装原則）。アニメーションや表示から状態を変えない。
- 攻撃のデータは Core の `[Serializable]` な設定クラス（`CombatTuning` / `AttackData`）に置き、`CharacterConfig.Combat` として ScriptableObject（`DefaultCharacter.asset`）で調整する。仮値は初期値の1か所にだけ書く。
- 命中の判定はキャラクターどうしの関係なので、`SimWorld` が全員のティックを進めた後に解決する。同じティックの相打ちが順番で変わらないよう、先に全員分の命中を集めてから、プレイヤーの番号の順に当てる（T3-2）。

### 3.1 T3-1 の仕様（今の動き）

| 項目 | 内容 |
|---|---|
| ボタン | 攻撃: マウスの右ボタン ／ キーボードの K ／ ゲームパッドの X（左の面のボタン）（D-35）。ワイヤー（左ボタン ／ J ／ RT）、ジャンプ（Space ／ A）は今までどおり |
| 攻撃の種類 | **地上**: 方向に関係なく「地上技」（入れた向きを向いて出す）。**空中**: 移動の入力（WASD ／ 左スティック）が上・下なら上・下の攻撃、横なら横の攻撃（その向きを向く）、入れていなければニュートラル。斜めは上下を優先【仮】 |
| 地上技の動き | 発生の間はその場、持続の間は前へ 16 m/s で踏み込み、硬直に入るときに前 9 m/s・上 11 m/s で飛び出して空中に移る（必ず上へ。値の検査で保証。D-35）。止まった状態から出すと、同じ時間走るより遠くへ進む。終わった後は空中ジャンプやワイヤーが使える |
| 始められるとき | Free のとき。ワイヤーを射出中・接続中は始められない（ワイヤー→攻撃のキャンセルは T3-4） |
| 攻撃中 | 移動・ジャンプ・ワイヤーの入力を無視し、向きも変えない。空中の攻撃は勢いのまま落ちる。押し続けても次の攻撃は出ない（もう一度押す）。硬直が終わったティックから次の行動ができる |
| 表示（仮） | 発生 = 黄、持続 = 赤、硬直 = 青。デバッグ表示（右上）に「Action Attack AirSide Active (9/25t)」のように出る |

## 5. 確認方法

- ロジックは Core のテスト（dotnet と Unity の EditMode）で確かめる。攻撃を含む入力で、巻き戻しても全員が同じ状態になることも確かめる。
- 状態の形式を変えたので（版 3）、それより前の入力の記録は `InputRecordings/archive/` に移した。戦闘がまとまった段階で、記録を作り直して PC 間で照合する（T3-9）。

### 5.1 T3-1 の確認の手順

1. Sandbox_Wire を再生する。
2. 地上で攻撃（右クリック ／ K ／ X）→ キャラが 黄 → 赤（前へ踏み込む）→ 青（上へ飛び出す）→ 元の色 と変わる。右上の「Action」の行に、攻撃の種類（Ground）と段階が出る。左右どちらを入れても「Ground」で、入れた向きへ進む。
3. ジャンプ中に攻撃 → 何も入れなければ「AirNeutral」、上・下・横を入れると「AirUp」「AirDown」「AirSide」。勢いのまま落ちる。
4. 地上技の後に、空中ジャンプやワイヤーですぐ動けるか（「素早く空中を動くために一度地上に降りる」使い方ができるか）。
5. 確認すること: 地上技の踏み込みと飛び出しの距離・高さ／ボタンの押しやすさ／斜めのときに上下が優先されるのが自然か。
