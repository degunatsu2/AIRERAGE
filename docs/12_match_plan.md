# 12. 試合ルール・コイン経済・目標地点の実装計画（Phase 4）

> ステータス: ドラフト v0.5（2026-10-14。D-24〜D-26、D-44〜D-48 とアディショナルタイムの細部のユーザーの決定、プレイテストの要望を反映）。数値はすべて【仮】です。仕様は [01](01_game_design.md) の 1〜3章と 6.8、完了条件は [05](05_roadmap.md) の Phase 4、判断事項は [02](02_open_decisions.md) の D-24〜D-26、D-44〜D-46。

## 1. 目的と範囲

**目的**: 1試合を最初から最後まで遊べるようにする。試合の開始・制限時間・終了・結果、撃破と復帰、コイン（出現・拾得・ドロップ・消滅・確定）、バンク地点を、ロールバック（Phase 2）の上で全員の画面が一致するように作る。

| 範囲に含める | 範囲に含めない |
|---|---|
| 試合の進行（カウントダウン、制限時間、終了、結果） | 参加コード、Relay、ロビーの画面（Phase 6） |
| 撃破後の復帰待ちと、復帰した後の無敵 | キャラクターごとの稼ぎ方の差（Phase 5） |
| コイン台帳（CoinLedger）と、コインの取引（[01](01_game_design.md) 3.2） | 本番用のアリーナ（Phase 6） |
| フィールドコイン、ダメージ報酬・撃破報酬、ドロップ | ハプニングイベント（ユーザーが検討中） |
| バンク地点（確定、争奪中の停止、移動） | |
| 終盤イベント、4人のオンライン対戦で1試合を最後まで | |

## 2. 構成の方針

- 試合のルールは Core の `MatchRules`（`Degunatsu.Core.Match`。`[Serializable]`、値は初期値の1か所）。`SimWorld` に渡す。
- **試合の段階（カウントダウン・試合中・終了）は、ティック数とルールだけから決まる**（`MatchRules.PhaseAt`）。段階を状態に持たないので、巻き戻しても全員で同じになり、状態の形式も増えない。
- 試合のルールはホストのものを全員が使う。試合の開始のメッセージ（`NetMessages.Start`）に、調整値といっしょに入れて送る（`OnlineSession.StartMatch(MatchRules)`）。
- 表示（`MatchHud`）は、ティック数とルールから段階と残り時間を求めて出す（`ISimulationFeed.CurrentTick` / `Rules`）。状態は書き換えない。
- コインは、シミュレーションの中のコイン台帳（CoinLedger）だけが増減させる（[01](01_game_design.md) 3.2）。台帳も状態に値で持ち、巻き戻しと PC 間のチェックサムに乗せる（T4-3 で設計する）。

### 3.1 T4-1 の仕様（今の動き）

| 項目 | 内容 |
|---|---|
| 段階 | カウントダウン（`CountdownTicks` = 180 ティック = 3 秒）→ 試合中（`DurationTicks` = 10800 ティック = 3 分。0 なら時間制限なし）→ 終了。ティック数だけから決まる（`MatchRules.PhaseAt`） |
| カウントダウン中 | 入力を無視する（重力やギミックは効く）。押し続けていたボタンは、始まったティックに押したとみなす（「GO!」と同時に動ける） |

| ルールの選び方 | ホストがロビーで「Timed match (3:00)」を選ぶ（外すと時間制限なし。カウントダウンと復帰は同じ）。値は Online オブジェクトの「Match」で変えられる。ホストの値を全員が使う |
| 検証用のシーン | Sandbox_Wire と Sandbox_Combat は時間制限なし・カウントダウンなし（`MatchRules.FreePlay()`）。撃破と復帰のルールは同じ |
| 終わった後 | 結果に「Restart」と「Quit」（3.4） |

### 3.2 T4-2 の仕様（今の動き）

| 項目 | 内容 |

| 撃破 | 撃破されてもコインは消えない（撃破のドロップは T4-6 で、台帳を通して落とす） |
| まだないもの | 報酬・ドロップ・確定の遊びのルール（T4-5〜T4-7）。出現と拾得、表示は T4-4（3.5） |

### 3.4 結果の画面のボタンと再戦（T4-9 の一部を先に。ユーザーの要望、2026-10-13）

|---|---|

### 3.5 T4-4 の仕様（今の動き）

| 項目 | 内容 |
|---|---|
| 出現 | 試合が始まったティックに、ふつうの出現地点の全部に出す。その後は、コインが拾われてから 10 秒（`MatchRules.CoinSpawnIntervalTicks` = 600）【仮】たつと、同じ地点にまた出す（拾われたときから地点ごとに数える。D-48。次に出せるティックは `CoinField.SpawnReadyTicks` に持ち、巻き戻しとチェックサムに乗る）。同じ地点のコインは1つまで。出現地点のコインは消えない【仮】。カウントダウン中と、試合が終わった後は出さない（検証用のシーンは始まりからずっと試合中） |

### 4.2 アディショナルタイム（D-25、D-45。T4-8 で作る）

- 時間切れのとき、確定コインで順位をつける。首位の確定コインを、ほかの人の「確定＋所持」が超えるなら（首位が同点なら、その場合も）アディショナルタイムに入る。
- アディショナルタイム中に、「確定＋所持」が首位の確定を超える人（逆転できる人）が拠点にたどり着いた時点で、その人の勝ちで試合が終わる。複数いれば早い者勝ち。時間切れの時点で足りなかった人も、アディショナルタイム中に稼いで条件を満たせばよい。
- 同点のときは、同点の人のうち、先に拠点にたどり着いた人が勝つ。

**細部の決定**（2026-10-13、ユーザー）:

1. アディショナルタイムは **5 秒**（20 秒から短くした。今のステージの広さでは 20 秒は長い。ユーザーの決定、2026-10-14）。逆転できる人がいなくなったら（攻撃を受けて所持コインを落とした、など）**その時点で終わる**。5 秒の間にだれも決めなければ、確定コインの順位のまま終わる（同点なら同順位【仮】）。
2. 首位の人が拠点にたどり着いたら、**首位の人の勝ちで終わる**。
3. アディショナルタイム中も、拠点は**移動する**。
