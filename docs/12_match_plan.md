# 12. 試合ルール・コイン経済・目標地点の実装計画（Phase 4）

> ステータス: ドラフト v0.1（2026-10-13）。数値はすべて【仮】です。仕様は [01](01_game_design.md) の 1〜3章と 6.8、完了条件は [05](05_roadmap.md) の Phase 4、判断事項は [02](02_open_decisions.md) の D-24〜D-26、D-44〜D-45。

---

## 1. 目的と範囲

**目的**: 1試合を最初から最後まで遊べるようにする。試合の開始・制限時間・終了・結果、撃破と復帰、コイン（出現・拾得・ドロップ・消滅・確定）、バンク地点を、ロールバック（Phase 2）の上で全員の画面が一致するように作る。

| 範囲に含める | 範囲に含めない |
|---|---|
| 試合の進行（カウントダウン、制限時間、終了、結果） | 参加コード、Relay、ロビーの画面（Phase 6） |
| 撃破後の復帰待ちと、復帰した後の無敵 | キャラクターごとの稼ぎ方の差（Phase 5） |
| コイン台帳（CoinLedger）と、コインの取引（[01](01_game_design.md) 3.2） | 本番用のアリーナ（Phase 6） |
| フィールドコイン、ダメージ報酬・撃破報酬（上限と減衰）、ドロップ | ハプニングイベント（ユーザーが検討中） |
| バンク地点（確定、争奪中の停止、移動） | |
| 終盤イベント、4人のオンライン対戦で1試合を最後まで | |

---

## 2. 構成の方針

- 試合のルールは Core の `MatchRules`（`Degunatsu.Core.Match`。`[Serializable]`、値は初期値の1か所）。`SimWorld` に渡す。
- **試合の段階（カウントダウン・試合中・終了）は、ティック数とルールだけから決まる**（`MatchRules.PhaseAt`）。段階を状態に持たないので、巻き戻しても全員で同じになり、状態の形式も増えない。
- 試合のルールはホストのものを全員が使う。試合の開始のメッセージ（`NetMessages.Start`）に、調整値といっしょに入れて送る（`OnlineSession.StartMatch(MatchRules)`）。
- 表示（`MatchHud`）は、ティック数とルールから段階と残り時間を求めて出す（`ISimulationFeed.CurrentTick` / `Rules`）。状態は書き換えない。
- コインは、シミュレーションの中のコイン台帳（CoinLedger）だけが増減させる（[01](01_game_design.md) 3.2）。台帳も状態に値で持ち、巻き戻しと PC 間のチェックサムに乗せる（T4-3 で設計する）。

### 3.1 T4-1 の仕様（今の動き）

| 項目 | 内容 |
|---|---|
| 段階 | カウントダウン（`CountdownTicks` = 180 ティック = 3 秒）→ 試合中（`DurationTicks` = 10800 ティック = 3 分。0 なら時間制限なし）→ 終了。ティック数だけから決まる（`MatchRules.PhaseAt`） |
| カウントダウン中 | 入力を無視する（重力やギミックは効く）。押し続けていたボタンは、始まったティックに押したとみなす（「GO!」と同時に動ける） |
| 終了の後 | 全員を止める（動き、命中、撃破なし。ティック数だけ進む） |
| 結果 | 「FINISH!」の 1.5 秒後に、画面の中央に順位を出す。順位は**仮に**、撃破した数（KO）が多い順、同じなら撃破された数（Fall）が少ない順、それも同じならプレイヤーの番号の順（`MatchResults.Rank`）。コインができたら（T4-4）コインの順に置き換える |
| 表示 | 始まる前に大きく「3」「2」「1」、始まると「GO!」（1 秒）。上の中央に残り時間（「2:59」。残り 10 秒で赤）。音: カウントダウンの電子音、GO!、FINISH!（合成。`ProceduralAudio`） |
| ルールの選び方 | ホストがロビーで「Timed match (3:00)」を選ぶ（外すと時間制限なし。カウントダウンと復帰は同じ）。値は Online オブジェクトの「Match」で変えられる。ホストの値を全員が使う |
| 検証用のシーン | Sandbox_Wire と Sandbox_Combat は時間制限なし・カウントダウンなし（`MatchRules.FreePlay()`）。撃破と復帰のルールは同じ |
| 終わった後 | 今は「Leave」で抜け、ホストがもう一度「Host」して、みんなが参加し直す（再戦は T4-9） |

### 3.2 T4-2 の仕様（今の動き）

| 項目 | 内容 |
|---|---|
| 復帰待ち | 撃破されたら、すぐに出現位置へ移り、`RespawnDelayTicks` = 180 ティック（3 秒）待つ（`CombatState.RespawnTicksLeft`）。待つ間は動かず、攻撃を受けず、表示では見えない。待つ間は、もう一度撃破にならない |
| 無敵 | 待つ間と、復帰した後の `InvincibleTicks` = 90 ティック（1.5 秒）は攻撃を受けない（`CombatState.InvincibleTicksLeft`）。復帰した後は点滅する。**自分が攻撃を出すと、そこで無敵が終わる【仮】**（無敵のまま一方的に攻撃できないように。D-44 で確認したい） |
| ボタン | 待つ間に押し続けたボタンは、戻った後に押したとみなさない（ワイヤーの射出などが勝手に起きない） |
| 表示 | 自分が待っている間は、画面の中央に「RESPAWN 3」「2」「1」 |

## 5. 確認方法

- ロジックは Core のテスト（dotnet と Unity の EditMode）で確かめる。試合の終わりをまたいだ巻き戻しでも全員が同じ状態になることと、オンラインでホストのルールが全員に届くことも確かめる。
- 状態の形式を変えた（版 14。復帰待ちと無敵）。

### 5.1 T4-1・T4-2 の確認の手順

1. `Sandbox_Online` を再生して **Host**。ロビーの「Timed match (3:00)」にチェックが入っていることを見て **Start**（1人でも始められる）。
2. 画面の中央に「3」「2」「1」「GO!」が出て、電子音が鳴る。カウントダウン中は動けない。上の中央に残り時間（2:59 から減る）。
3. ステージの外に落ちる → キャラクターが消えて「RESPAWN 3」「2」「1」→ 出現位置に戻って 1.5 秒点滅する（点滅中は攻撃を受けない。攻撃を出すと点滅が止まる）。
4. 3 分待つ（短くしたいときは、ホストの Online オブジェクトの「Match」→「Duration Ticks」を 1800（30 秒）などにする）→ 残り 10 秒で時間が赤くなり、0:00 で「FINISH!」と音、全員が止まる → 1.5 秒後に結果（順位、KO、Fall）。
5. 友達と（docs/11 5.12 と同じ）: 全員の画面で、カウントダウン、残り時間、終わり、結果の順位が同じか。
6. 確認すること: 3 分の長さ、カウントダウン 3 秒、復帰待ち 3 秒と無敵 1.5 秒の長さ、「攻撃で無敵が終わる」でよいか、表示の大きさと位置。
