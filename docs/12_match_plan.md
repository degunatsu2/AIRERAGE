# 12. 試合ルール・コイン経済・目標地点の実装計画（Phase 4）

> ステータス: ドラフト v0.3（2026-10-13。D-24〜D-26、D-44〜D-46 とアディショナルタイムの細部のユーザーの決定を反映）。数値はすべて【仮】です。仕様は [01](01_game_design.md) の 1〜3章と 6.8、完了条件は [05](05_roadmap.md) の Phase 4、判断事項は [02](02_open_decisions.md) の D-24〜D-26、D-44〜D-46。

## 1. 目的と範囲

**目的**: 1試合を最初から最後まで遊べるようにする。試合の開始・制限時間・終了・結果、撃破と復帰、コイン（出現・拾得・ドロップ・消滅・確定）、バンク地点を、ロールバック（Phase 2）の上で全員の画面が一致するように作る。

| 範囲に含める | 範囲に含めない |
|---|---|
| 試合の進行（カウントダウン、制限時間、終了、結果） | 参加コード、Relay、ロビーの画面（Phase 6） |
| 撃破後の復帰待ちと、復帰した後の無敵 | キャラクターごとの稼ぎ方の差（Phase 5） |
| コイン台帳（CoinLedger）と、コインの取引（[01](01_game_design.md) 3.2） | 本番用のアリーナ（Phase 6） |
| フィールドコイン、ダメージ報酬・撃破報酬（上限と減衰）、ドロップ | ハプニングイベント（ユーザーが検討中） |
| バンク地点（確定、争奪中の停止、移動） | |
| 終盤イベント、4人のオンライン対戦で1試合を最後まで | |

## 2. 構成の方針

- 試合のルールは Core の `MatchRules`（`Degunatsu.Core.Match`。`[Serializable]`、値は初期値の1か所）。`SimWorld` に渡す。
- **試合の段階（カウントダウン・試合中・終了）は、ティック数とルールだけから決まる**（`MatchRules.PhaseAt`）。段階を状態に持たないので、巻き戻しても全員で同じになり、状態の形式も増えない。
- 試合のルールはホストのものを全員が使う。試合の開始のメッセージ（`NetMessages.Start`）に、調整値といっしょに入れて送る（`OnlineSession.StartMatch(MatchRules)`）。
- 表示（`MatchHud`）は、ティック数とルールから段階と残り時間を求めて出す（`ISimulationFeed.CurrentTick` / `Rules`）。状態は書き換えない。
- コインは、シミュレーションの中のコイン台帳（CoinLedger）だけが増減させる（[01](01_game_design.md) 3.2）。台帳も状態に値で持ち、巻き戻しと PC 間のチェックサムに乗せる（T4-3 で設計する）。

### 4.2 アディショナルタイム（D-25、D-45。T4-8 で作る）

- 時間切れのとき、確定コインで順位をつける。首位の確定コインを、ほかの人の「確定＋所持」が超えるなら（首位が同点なら、その場合も）アディショナルタイムに入る。
- アディショナルタイム中に、「確定＋所持」が首位の確定を超える人（逆転できる人）が拠点にたどり着いた時点で、その人の勝ちで試合が終わる。複数いれば早い者勝ち。時間切れの時点で足りなかった人も、アディショナルタイム中に稼いで条件を満たせばよい。
- 同点のときは、同点の人のうち、先に拠点にたどり着いた人が勝つ。

**細部の決定**（2026-10-13、ユーザー）:

1. アディショナルタイムは **20 秒**。逆転できる人がいなくなったら（攻撃を受けて所持コインを落とした、など）**その時点で終わる**。20 秒の間にだれも決めなければ、確定コインの順位のまま終わる（同点なら同順位【仮】）。
2. 首位の人が拠点にたどり着いたら、**首位の人の勝ちで終わる**。
3. アディショナルタイム中も、拠点は**移動する**。
4. **毎秒 5 枚ずつの確定はなくす**。拠点にたどり着いたときにだけ、所持コインを確定する（アディショナルタイム中に限らず、いつでも）。

- 4 の読み方【仮】: 拠点の中に入ると、所持コインを全部その場で確定する（中にいる間に新しく持ったコインも、すぐ確定）。敵が拠点の中にいても止まらない（「敵がいると確定が止まる」争奪の仕様はなくなる。拠点で待ち構える相手との戦いが争奪になる）。

## 5. 確認方法

- ロジックは Core のテスト（dotnet と Unity の EditMode）で確かめる。試合の終わりをまたいだ巻き戻しでも全員が同じ状態になることと、オンラインでホストのルールが全員に届くことも確かめる。
- 状態の形式を変えた（版 14 で復帰待ちと無敵、版 15 でコイン）。

### 5.1 T4-1・T4-2 の確認の手順

1. `Sandbox_Online` を再生して **Host**。ロビーの「Timed match (3:00)」にチェックが入っていることを見て **Start**（1人でも始められる）。
2. 画面の中央に「3」「2」「1」「GO!」が出て、電子音が鳴る。カウントダウン中は動けない。上の中央に残り時間（2:59 から減る）。
3. ステージの外に落ちる → キャラクターが消え、出現位置の周りに大きな円形のゲージ（「RESPAWN」）が出て短くなっていく → なくなると戻って 1.5 秒点滅する（点滅中は攻撃を受けない。攻撃を出すと点滅が止まる）。
4. 3 分待つ（短くしたいときは、ホストの Online オブジェクトの「Match」→「Duration Ticks」を 1800（30 秒）などにする）→ 残り 10 秒で時間が赤くなり、0:00 で「FINISH!」と音、全員が止まる → 1.5 秒後に結果（順位、KO、Fall）。
5. 友達と（docs/11 5.12 と同じ）: 全員の画面で、カウントダウン、残り時間、終わり、結果の順位が同じか。
6. 確認すること: 3 分の長さ、カウントダウン 3 秒、復帰待ち 3 秒と無敵 1.5 秒の長さ、「攻撃で無敵が終わる」でよいか、表示の大きさと位置。
