# 19. チーム対戦モードの計画と進捗

ユーザーの要望（2026-11-02）を整理したもの。判断事項 D-78〜D-86（4 章。[02](02_open_decisions.md) B-5）は**すべて推奨どおりに決定**（2026-11-02、
ユーザー）。D-78 の均等に分けるボタンは、チームごとの人数の配分を指定でき、その配分のとおりにランダムに割り当てる。今の個人戦（最大 4 人）の
遊び方は変えない。進捗は 5 章（T9-1〜T9-5 と観戦の待機所を作った。確認の手順は 6 章・7 章）。

## 1. ユーザーの要望

- ネットワーク対戦とローカル対戦の両方に、チーム対戦のモードを足す。
- 待機所に最大 4 色のチームを出し、それぞれにプレイヤーが入る形でチームを分ける。
- このモードは最大 8 人まで参加できる。
- 手持ち（所持）コインは一人ずつ。バンク（確定）のコインはチームで共有する。試合の終わりに、バンクのコインがいちばん多いチームの勝ち。
- 味方には攻撃が当たらず、敵にだけ当たる。例外は THIEF の Q（タレントスナッチ）の 1 段目の弾で、味方にも当たる（味方の技をコピーできる）。

## 2. 今の作りで変わるところ（調べた結果）

| 部分 | 今 | チーム対戦で必要なこと |
|---|---|---|

| 確定コイン | `CharacterState.Coins.Banked`（一人ずつ）。順位・勝敗・アディショナルタイム・撃破報酬の順位の差・逆転の恩恵（`CatchUpRules`）・王冠がこれを見る | チームの確定 = 味方の `Banked` の合計とする（状態は増やさず、一人ずつの記録も残る）。順位・勝敗などを「チームの合計」で比べる関数に置き換える |
| 命中 | `HitResolver` は自分以外の全員に当たる | 同じチームには当てない（THIEF の Q の 1 段目だけ例外）。置かれた物（地雷・クリーム・ミラーボールなど）と、技の効果（感電・凍結・吸い込み）も同じ扱いにするか（D-81） |

## 5. 進捗

  - **T9-1 重さ**: 8 人の試合で、1 フレームに 8 ティックを巻き戻して進め直す最悪の場合（予測の上限 8F。D-34）が **0.39 ms**（1 ティック
    0.043 ms。クラウドの Linux / .NET 8。`TeamTests.EightPlayers_StepAndRollbackCost`。`[Explicit]` なので `dotnet test --filter Name~EightPlayers`
    で測る）。Unity（Mono）は数倍遅いとしても、60fps の 1 フレーム 16.6 ms に十分に収まる。
  - **T9-2 チームの決まり**: チームの番号は `CombatState.Team`（1〜4。0 は個人戦。状態の形式は版 32）。試合を始める前に `SimWorld.SetTeam` で
    決める（撃破されて戻っても、抜けても変わらない）。`TeamRules`: 味方か（`Allies`）、チームの確定の合計（`ScoreOf`）、チームの確定＋所持
    （`PotentialOf`。抜けた人の所持は数えない）、順位（`RankOf`。チームは 1 回だけ数える）、均等に分けるボタンの割り当て（`Distribute`。
    人数の配分と試合の種から決まる）。順位・結果の並び（`MatchResults.Rank`。同じチームは並べてまとめ、アディショナルタイムで勝った人の
    チームがいちばん上）・アディショナルタイム（`MatchFlow.CanWinAtTheBank`・`IsSoleLeader`）・撃破報酬の順位の差・逆転の恩恵（チームの全員が
    同じ順位）・右上の王冠を、チームの合計で決める。チームがなければ今までと同じ。
  - **T9-3 味方に当たらない**: 近い攻撃（`HitResolver`）、投射物・置かれた物の命中（`HitResolver` の extraHits と、各技の規則の持ち主の確かめ:

    Q をコピーする（ダメージはない。D-82）。CPU は味方を狙わない（`CpuPlayer`・`CpuMotion`）。
  - まだ: ステージに効果を広げる置かれた物のうち、当たり判定を持たないもの（クリーム・風の帯など）は、今は味方にも敵にも同じに効く
    （D-81 の「味方の得になる物は味方も使える」はそのまま、害のある面だけを味方から外すのは T9-6 で画面と一緒に確かめる）。

  - **チームの見出しで入る**: 列の見出し（RED n・BLUE n・GREEN n・YELLOW n）を選んで決定（クリック）すると、自分がそのチームに入る。

    札の決定で人を移せる（チーム対戦は RED → BLUE → GREEN → YELLOW → 観戦 → RED、個人戦は参加 ↔ 観戦）。観戦の人は準備完了を待たず、

    確定したティックの全員の入力（`RollbackSession.TickConfirmed`）を送り、観戦の人はそれで同じワールドを進める（`SpectatorSession`。
