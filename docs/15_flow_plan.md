# 15. ゲームの流れ・ステージの仕組み・セッション（Phase 6）の実装計画

[05](05_roadmap.md) Phase 6 の詳細。D-54（ゲームの流れ）、D-16（参加コード）、D-58（シングルモードは Phase 7 の CPU）に従う。

## 1. 目的と範囲

起動 → タイトル → メインメニュー →（対戦を選んだら）キャラクター選択 → ステージ選択 → 対戦 → 結果 → メニュー の流れを作る（D-54）。
ステージをデータ（シーンと設定）で追加でき、ステージ選択に並ぶようにする。ローカル対戦（1 台の PC に複数のコントローラー）、トレーニング、
ネットワーク対戦、オプションをメニューから選べるようにする。

**範囲の外**: キャラクターの調整（T5-7。[13](13_character_plan.md) 12 章。ユーザーのプレイテストの後に、Phase 6 と並行して行う）、CPU（Phase 7。
D-58。メニューの「シングル」は Phase 7 まで選べない表示にする）、ステージの数をそろえること（Phase 7）、本番の見た目（Phase 8）。

**完了条件**（[05](05_roadmap.md) Phase 6）:
- タイトルからメニュー、キャラクター選択、ステージ選択、対戦、結果、メニューへ戻るまでが動く [手動]
- ローカル対戦（1 台の PC に複数のコントローラー）で遊べる [手動]
- ステージをデータ（シーンと設定）で追加でき、ステージ選択に出る [手動＋自動]
- オプション（音量、キーの割り当て、画面）が保存される [手動]
- 参加コードでの接続（D-16）。クライアントとホストの切断の扱い [手動]

## 6. 作ったもの

### 6.1 骨組み（T6-1）

- **シーン**（D-66）: `App`（いつも読み込む。`GameFlow` と EventSystem。ビルドの最初のシーン）、`Menu`（タイトルとメインメニュー）、
  ステージのシーン（`Stages/Stage_Athletic`）、試合の仕組みのシーン（`Modes/Match_Training`）。`GameFlow` が画面ごとのシーンを重ねて
  読み込み、ステージのシーンを有効にする（光と空）。選んだものはシングルトンや静的な変数を使わずに渡す（試合の仕組みは、読み込んだ
  ステージの物をシーンの中から探す）。ビルドの設定のシーンの順は App が最初（テンプレートの `SampleScene` は一覧から外した。ファイルは残した）。
- **タイトル**: 大きな「AIRERAGE」と、点滅する「PRESS ANY BUTTON」。どれかのキー・ボタンでメインメニューへ（最初の 1 回だけ。メニューへ戻ったときはメインメニューから）。
- **メインメニュー**（uGUI。D-65）: 左に縦に並んだ斜めの札（右上の札と同じ形。`SlantedPlate`）。SINGLE（Phase 7 の CPU まで「COMING SOON」で選べない）、
  LOCAL VS（T6-5 まで選べない）、NETWORK VS、TRAINING、OPTIONS（T6-9 まで選べない）、QUIT。キーボード（矢印・Enter・Esc）、ゲームパッド
  （スティック・十字キー・A・B）、マウス（乗せると選ぶ）。選んでいる札は縁が水色になって少し右へ出る。戻る（Esc・B）でタイトルへ。
  後ろにアスレチックステージをゆっくり横切って映す（D-69 の (b)。`MenuCameraDrift`）。
- **NETWORK VS**: 今はオンラインの検証用のシーン（`Sandbox_Online`）をそのまま開く（T6-7 でステージと分け、メニューの流れに組み込む）。
  つなぐ前の画面の「Back to menu」と、結果の「Quit」でメニューへ戻る（App から始めたときだけ。直接開いたときは今までどおりゲームを終える）。
- **一時停止**（オフラインの試合と検証用のシーン。`PauseMenu`）: Esc かゲームパッドの Start で開いてシミュレーションを止める。RESUME、
  RESET POSITION（出現位置に戻す）、BACK TO MENU（App から始めたときだけ）。入力に `Pause` を足し、**ゲームパッドの Start を位置のリセットから
  一時停止に変えた**（位置のリセットはキーボードの Backspace のまま。ゲームパッドでは一時停止のメニューの RESET POSITION）。
- 文字は Unity に入っている字体（LegacyRuntime）を使う（字体のファイルは足していない。TextMesh Pro の字体は Git LFS の対象になるため）。

### 6.2 ステージのデータ（T6-2）

- `StageDefinition`（名前、シーンの名前、説明、色）と `StageCatalog`（並ぶ順。最初のステージをメニューの背景にも使う）。`Data/Stages/` に置く。
- ステージのシーンには、地形・ギミック・撃破の範囲・コインの出現地点・拠点の候補・出現位置（新しい `SpawnPointAuthoring`。番号の順）・光だけを置く。
  アスレチックステージは `Sandbox_Online` と同じ配置（値は `SandboxOnlineSceneBuilder` の 1 か所）。
- `SimulationRunner` は、出現位置が設定されていなければ、読み込んだステージのシーンの出現位置を使う（1 番目が自分、2 番目からダミー）。
- シーンは `FlowSceneBuilder`（メニューの「Airerage/ゲームの流れのシーンを作り直す」）で作る。

### 6.3 トレーニング（T6-6）

- メインメニューの TRAINING で、最初のステージ（アスレチック）に、自分とダミー 3 体（ステージの 2〜4 番目の出現位置）。前に選んだキャラクター
  （オンラインの待機所と同じく覚えている）で始まり、F3 で変えると覚える。`Sandbox_Combat` と同じ表示・HUD・デバッグの操作（F7・F8 など）。
- ステージとキャラクターの選択の画面は T6-3・T6-4 で作る（それまでは、最初のステージと前に選んだキャラクター）。

### 6.4 メニューの効果音（ユーザーの要望、2026-10-16。仮の音）

- 合成した 3 つの音（`ProceduralAudio`）: カーソルの移動（`UiMove`。短く軽い「ピッ」）、決定（`UiConfirm`。上がる 2 音の「ピロン」）、
  一時停止を開く（`UiPause`。下がる 2 音と低い「トン」）。
- 鳴らすとき: メニューの項目・キャラクターの札・ステージの札にカーソルが来た（キーボード・ゲームパッドで動かした、マウスを乗せた）、
  決定した（タイトルを抜けた、項目・キャラクター・ステージを決めた、一時停止の項目、オンラインの Host・Join・START・Back to menu、
  結果の Restart・Quit）、Esc・Start で一時停止を開いた。待機所のキャラクターの「<」「>」は移動の音。画面を開いたときに最初の項目を
  選ぶときは鳴らさない。
- 音は `UiSounds` が鳴らす。いつも読み込む App のシーンに置く（決定した直後に画面のシーンを外しても途切れない）。検証用のシーンを
  直接再生したときは、そのシーンに作る。本番の音ができたら `UiSounds` の差し替えの音に入れる。

### 6.5 キャラクター選択とステージ選択（T6-3、T6-4）

- TRAINING → **キャラクター選択** → **ステージ選択** → トレーニング。戻る（Esc・B）で 1 つ前の画面へ（キャラクター選択から戻ると、
  メインメニューの TRAINING にいる）。
- キャラクター選択（`CharacterSelectScreen`）: 上に「CHARACTER SELECT」、真ん中に 4 体の札（ロゴと名前。左右で選ぶ。選んでいる札は上へ出る）、
  下にカーソルのあるキャラクターの大きなロゴ・名前・技（GROUND・KO・Q・E・R の技の名前）。カーソルは前に選んだキャラクターから始まる。
  決めたキャラクターは覚えておく（オンラインの待機所と同じ）。
- ステージ選択（`StageSelectScreen`）: 左にステージの札（今はアスレチックの 1 つ）、右にカーソルのあるステージの名前と説明（ステージの色の帯）。
- 札はシーンを作るときに、キャラクターの一覧とステージの一覧から作る（キャラクターやステージを足したら、`FlowSceneBuilder` で作り直す）。
- 4 人の参加（ローカル対戦）と、試合の設定（制限時間など）は T6-5 で足す。

### 6.6 キャラクター選択の配置の修正（ユーザーの指摘、2026-10-17）

- **原因**: 下の説明（ロゴ・名前・技）を、画面の高さに対する割合と固定の大きさを混ぜて置いていた。横に長い画面（例: 1421×682）では高さが
  1080 の基準より小さくなり、ロゴ・名前・技が重なった。
- **配置**: 上の題と札は画面の上から、下の説明は画面の下から固定の大きさで置く（高さ 1000 まで重ならない）。下の説明は、左にロゴ、その右に
  名前、名前のすぐ右にハッシュタグ（`HorizontalLayoutGroup` で名前の長さに合わせる）、その下に Q・E・R の 3 列（左から）。各列は
  技の名前（カタカナ）、何ができるか（4 行まで）、その下にクールタイム（スタックが 2 以上なら「スタック 2」、効果の後に数える技は
  「（効果が終わってから）」「（壊されてから）」）。R は「必要ゲージ 70%」。
- **ハッシュタグ**: STANDARD「#特徴無し」、RISK TAKER「#コイン重視 #大器晩成」、STORM RUNNER「#高速 #高機動 #風」、
  SPACE TRAVELER「#変則的 #遠距離」。
- **文の置き場所**: ハッシュタグと技の名前・説明は表示だけの値なので、キャラクターのアセット（`CharacterConfigAsset` の Tags と
  `SkillText`）に持ち、シーンのビルダーが `CharacterProfiles`（エディタ）の値で作り直す（値はコードの 1 か所）。クールタイム・スタック数・
  必要なゲージは、キャラクターの調整値（`CombatTuning`）から画面が出す（調整しても文を直さなくてよい）。説明には調整で変わる数値を書かない。
- **日本語の字体**: Unity に入っている字体（LegacyRuntime）には日本語の字がない。ハッシュタグと技の文字は、PC に入っている日本語の字体
  （Windows なら Yu Gothic UI・Meiryo など。`JapaneseFont`）で書く。字体のファイルは足さない。
- **画像での確認**: クラウドの仮想の画面でメニューの画面の画像を撮れるようにした（`UiSnapshot`。docs/08 4.2）。16:9・横に長い画面・16:10 で、
  重ならず、日本語が出ることを確かめた（クラウドの字体での見た目。Windows の字体での見た目は未確認）。

### 6.7 一時停止を Esc で閉じる（ユーザーの指摘、2026-10-17）

- **原因**: Esc は一時停止の入力（Pause）でもあり、UI の戻る操作でもある。開いているときに Esc を押すと、戻る操作で閉じた同じフレームに、
  Pause で開き直していた（どちらが先に処理されるかで、閉じないように見えた）。
- **修正**: 開け閉めは 1 回の押下で 1 回だけにした（閉じたフレームには開き直さない）。もう一度 Esc（ゲームパッドは Start か B）で閉じる。
  RESUME と同じ。仮想のキーボードで Esc を押すテスト（`PauseMenu_EscapeAgain_Closes`）で、直す前に失敗することを確かめた。

### 6.8 ローカル対戦（T6-5。D-67）

- **流れ**: メインメニューの LOCAL VS → 参加とキャラクター選択（`LocalJoinScreen`）→ ステージ選択 → ローカル対戦（`Match_Local` をステージの
  シーンに重ねる）。ステージ選択から戻ると、参加した人とキャラクターはそのまま（READY だけ外す）。
- **参加の画面**: 4 人分の枠。キーボード＋マウスで 1 人、ゲームパッド 1 つで 1 人（参加した順に P1〜P4。色はオンラインと同じ）。
  参加は Enter・Space ／ A・Start、キャラクターは左右（A・D・矢印 ／ 十字キー・左スティック）、決定で READY、戻る（Esc・Backspace ／ B）で
  READY の取り消し、もう一度で抜ける（だれも参加していなければメインメニューへ）。2 人以上が参加して全員が READY でステージ選択へ。
  時間の制限（あり 3 分 ／ なし）は T ／ Y で切り替える。最初に参加した人のキャラクターは、前に選んだキャラクター（トレーニングと同じ）。
- **試合**（`LocalMatchRunner`）: オンラインと同じ `SimWorld`（試合のルール、コイン、拠点、撃破、結果）。ロールバックはしない。人ごとに
  入力のアセットを複製して機器を限る（`InputActionAsset.devices`）。マウスの照準はキーボードの人だけ（ゲームパッドの人は右スティック）。
  シーンを直接再生したときは、キーボード＋マウスとつながっているゲームパッドで始める（足りなければ 2 人目は動かない相手）。
- **カメラ**（`SharedCamera`）: 全員（復帰待ちを除く）が入る範囲の中心を追い、範囲が収まるように距離を変える（30〜60m【仮】）。
  それより離れた人は画面の端の札で示す（`PlayerGuides`）。マウスホイールのズームはない。
- **HUD**: 技の札は人ごと（画面の下を人数で等分し、上に P1 などの名前。狭ければ縮める。`SkillHud` の _player）。頭上の通知もその人の
  キャラクターに。コンボはだれのものでも出す（「P1 > P2」。`ComboHud` の _everyone）。右上の札・タイマー・お知らせ・結果はオンラインと同じ。
- **一時停止**: だれの Esc・Start でも開く。対戦なので RESET POSITION はない（`IPauseTarget`）。BACK TO MENU でメニューへ。
- **結果**: Restart で同じ人・同じキャラクターで始め直し、Quit でメニューへ。結果のボタンは今の HUD（IMGUI）なのでマウスで押す
  （ゲームパッドだけのときは、一時停止の BACK TO MENU で戻れる）。ゲームパッドで押せる結果の画面と「キャラクター選択へ」は T6-8 で作る。
