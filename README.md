# degunatsu

Unity / C# で制作する、2.5D横視点のワイヤーアクション型オンラインPvPゲーム（1試合4人、プレイヤーホスト型）。

ワイヤーによる高速移動と空中コンボを軸に、コイン争奪・キャラクター対戦・目標争奪を1つの試合の中で統合します。

## 現在の状態

設計段階です（Unity プロジェクトはまだありません）。
